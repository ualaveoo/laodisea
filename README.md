# La Odisea — Prototipo Episodio 1

Prototipo web listo para publicar en GitHub Pages.

## Archivos
- `index.html`: juego completo.
- `assets/intro.mp4`: intro en video.
- `assets/portada.webp`: portada aprobada.
- `assets/odiseo.webp`: personaje de Odiseo.
- `assets/penelope.webp`: personaje de Penélope.
- `assets/musica.mp3`: música de fondo del episodio.

## Publicar en GitHub Pages
1. Crear un repositorio nuevo.
2. Subir **el contenido de esta carpeta manteniendo la carpeta `assets`**.
3. En GitHub: `Settings` → `Pages`.
4. En `Build and deployment`, seleccionar `Deploy from a branch`.
5. Seleccionar rama `main` y carpeta `/ (root)`.
6. Guardar y esperar a que GitHub publique el enlace.

No requiere servidor ni instalación. Funciona como sitio estático.

## Controles
- PC: flechas o WASD.
- Móvil/tablet: control táctil en pantalla.
- Música y sonidos se pueden activar/desactivar por separado.

## Estructura del prototipo
- Portada.
- Video de introducción.
- Presentación del Episodio 1: La isla de los lotófagos.
- Nivel 1: lluvia de loto.
- Nivel 2: río y obstáculos móviles.
- Nivel 3: tormenta de loto y lotófagos.
- Flores de moly: +100 puntos.
- Final: tesoro “Brújula de Ítaca”.

Cada nivel está configurado para 2 minutos.
