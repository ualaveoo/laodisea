## Controles
- Flecha ↑: avanzar
- Flecha ↓: retroceder
- Flecha ← / →: moverse lateralmente

## GitHub Pages
1. Crear un repositorio nuevo.
2. Subir `index.html`, `README.md` y la carpeta `assets`.
3. Ir a Settings → Pages.
4. En Build and deployment seleccionar `Deploy from a branch`.
5. Seleccionar la rama `main` y `/ (root)`.
6. Guardar.

No requiere instalación, npm ni servidor especial.
